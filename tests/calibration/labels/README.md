# Calibration labels

One file per corpus skill: `labels/<skill>.json`, where `<skill>` is the corpus `name`.

```json
{"skill": "good-skill", "gates": {"TRG-CG1": "yes", "SAF-B1": "no"}}
```

- `gates` maps each gate id that applies to that skill to `"yes"` or `"no"`.
- The maintainer writes labels by hand, after reading the skill. Labels are never generated by a
  model, and never copied from a reviewer run: they are the independent reference that Cohen's
  kappa (target S4, 0.6 or more) is measured against.
- Labels are created once. Changing one needs a written reason in `support/proven-runs.md`.
